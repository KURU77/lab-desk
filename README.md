# 研究デスク

進行中の研究をまとめて管理するアプリです。研究ごとに **概要・先行研究・費用と備品・進捗・これからの予定** を一か所に置き、手持ちの **電子部品や工具の台帳** もあわせて記録できます。

**→ https://kuru77.github.io/lab-desk/**

依存ライブラリなしの `index.html` 1枚。データはブラウザの localStorage にだけ保存され、外部へは送信しません。オフラインでも開けます（先行研究の [DOI 取り込み](#先行研究の取り込み)のときだけ、DOI を CrossRef の公開 API に問い合わせます）。

## 画面

| タブ | 内容 |
|---|---|
| 研究 | 研究の一覧（状態で絞り込み）、費用の合計、2週間以内の予定 |
| 予定 | 全研究の予定を「期限切れ / 今週 / 今月 / それ以降 / 期限なし」でまとめて表示。その場でチェックできる |
| 部品・工具 | 手持ちの部品・工具・計測器の台帳。研究で使っているかどうかに関わらず登録できる |
| 設定 | テーマ、バックアップ、CSV 書き出し、サンプルデータ |

### 研究ごとのページ

| | |
|---|---|
| 概要 | テーマ・状態（進行中 / 計画中 / 中断 / 完了）・期間・概要・研究課題・方法・成果物・タグ。次にやることと最新の記録もここに |
| 先行研究 | 論文・書籍・データシートなどの出典。著者・年・掲載誌・DOI/URL・状態（未読 / 読んだ / 精読済み / 引用予定）・この研究との関係メモ。**一覧をコピー** で引用リストとして書き出せる |
| 費用・備品 | かかった費用（区分ごとの内訳つき）と、台帳から紐づけた備品。費用を記録するときに「台帳にも登録」を選ぶと、部品登録と備品への追加まで一度に済む |
| 進捗 | 進度（予定の完了率から自動計算、または手動）と、日付つきの研究記録 |
| 予定 | 節目やタスクを期限つきで。超過・7日以内は色で知らせる |

### 部品・工具の台帳

- 分類：マイコン・ボード / センサ / 表示・LED / モーター・駆動 / 電源・電池 / 受動部品 / 半導体・IC / 通信モジュール / コネクタ・配線 / 基板・ブレッドボード / 工具 / 計測器 / 材料・消耗品 / その他
- 型番・数量・単位・保管場所・単価・購入日・購入先・URL・タグ・メモ
- 一覧の **− / ＋** で数量をすぐ増減。「これ以下で補充」を決めておくと、減ったときに赤で表示され、「補充したいものだけ」で絞り込める
- どの研究で使っているかを部品側からも確認できる

## 先行研究の取り込み

追加画面の上の欄に貼って **読み取る** を押すと、書誌が埋まります。

| 貼るもの | 動作 |
|---|---|
| BibTeX | title / author / year / journal・booktitle / doi / url を取り出す（通信なし） |
| DOI（`10.xxxx/...` や `https://doi.org/...`） | CrossRef から書誌を取得 |
| arXiv の URL | arXiv の DOI に変換して CrossRef から取得 |

## データの持ち運び

- **設定 → バックアップを書き出す** で JSON を保存、**読み込む** で復元（端末の移動にも）
- 費用の一覧、部品・工具の台帳は CSV で書き出せます（Excel で文字化けしないよう BOM 付き UTF-8）

## iPhone で使う

Safari で上の URL を開き、共有ボタン →「ホーム画面に追加」。
